# Resin v1.6.2

- 点击 IPv6 管理页顶部的「号段管理」卡片，可在弹窗中添加、编辑、删除和验证号段。
- 保存代理后，界面按已启用的 SOCKS5 接入端口生成可复制的 `socks5h://用户名:密码@主机:端口` 链接。账号绑定多个端口时，每个端口生成一条链接。
- IPv6 代理列表支持勾选、全选、批量复制和批量删除。每行可单独复制代理链接或不带 `/64` 的 IPv6 地址。
- 已有账号首次复制链接时需要输入原密码。密码在当前浏览器标签页的会话中保留，便于后续复制。

安装包和 Docker 镜像由 GitHub Actions 构建。使用自动添加 IPv6 地址功能的 Docker 部署，请按[中文说明](https://github.com/Victor-Tau/Resin/blob/v1.6.2/README.zh-CN.md#一个-ipv4-socks5-端口为不同账号分配固定-ipv6)配置主机网络和 `CAP_NET_ADMIN`。
