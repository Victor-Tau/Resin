# Resin v1.5.0

此版本为 Victor-Tau/Resin fork 的首个正式版，基于上游 v1.4.1。

- 一个 IPv4 SOCKS5 端口可按用户名和密码将连接映射到不同的固定公网 IPv6。管理员可以在 WebUI 查看网卡前缀，逐账号分配地址，或使用管理 API 批量配置。Linux 上的 Resin 可自动添加地址并在重启后恢复映射。
- 修复了节点池将 SOCKS5 已发送数据、上游返回 0 字节的会话记作成功的问题。
- 节点池默认每 24 小时探测出口，连续失败 3 次触发熔断，连续获得 2 次有效出口 IP 后恢复。这三项均可配置。首次上线且尚无失败记录的节点通过一次出口验证即可参与路由。

GitHub Actions 编译并发布各平台的程序包。使用单核 Linux 服务器时，可直接下载对应架构的附件并向 Resin 服务授予 `CAP_NET_ADMIN` 以启用自动地址分配。Docker 的能力配置和账号映射示例见 [部署说明](https://github.com/Victor-Tau/Resin/blob/v1.5.0/README.zh-CN.md#一个-ipv4-socks5-端口为不同账号分配固定-ipv6)。
