# Resin v1.6.0

- WebUI 新增独立的 IPv6 管理页，用图示串起号段、代理账号和连接端口。
- 可以保存服务器检测到的公网 `/64` 号段，也可以手动填写运营商分配的号段。号段支持自定义标签，新建代理时可以按标签选择。
- 每批可创建 1 到 20 个 SOCKS5 账号。选择号段后，表单自动生成该号段内的 IPv6 地址和包含字母与数字的 8 位密码。
- 一个 IPv6 代理账号可以绑定到多个 SOCKS5 接入点。修改号段标签或删除号段记录时，已有代理继续使用原地址。升级前的 IPv6 映射可在新页面编辑或删除，并沿用原接入点。

自动添加 IPv6 地址需要 Linux 及 `CAP_NET_ADMIN`。配置和部署步骤见 [中文使用说明](https://github.com/Victor-Tau/Resin/blob/v1.6.0/README.zh-CN.md#一个-ipv4-socks5-端口为不同账号分配固定-ipv6)。
