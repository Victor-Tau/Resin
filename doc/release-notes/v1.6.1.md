# Resin v1.6.1

- IPv6 管理现在从网卡配置和 Linux 直连路由发现号段。从 `/56` 到 `/64` 的号段会展开为候选 `/64`，可以加标签保存并用于创建 SOCKS5 代理。
- 新增号段可用性验证。Resin 会临时添加一个随机地址，分别报告网卡是否接受该地址以及公网是否看到同一个出口地址，随后移除测试地址。
- 可以重新检测号段，也可以手动输入运营商分配的 `/64` 后验证。候选列表按网卡和上级号段分组。

自动添加 IPv6 地址需要 Linux 及 `CAP_NET_ADMIN`。操作步骤见 [中文使用说明](https://github.com/Victor-Tau/Resin/blob/v1.6.1/README.zh-CN.md#一个-ipv4-socks5-端口为不同账号分配固定-ipv6)。
