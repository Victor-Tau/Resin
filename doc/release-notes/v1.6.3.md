# Resin v1.6.3

- IPv6 代理密码以明文保存到 Resin 数据库。刷新页面、重新登录或更换浏览器后，单条和批量复制仍可直接生成带凭据的 SOCKS5 链接。
- 升级前只存了密码哈希的账号仍可正常连接。在「编辑代理」中填写原密码或新密码并保存，即可启用直接复制。
- 代理列表和编辑表单使用不带 `/64` 的 IPv6 地址，号段继续使用 CIDR 格式。

安装包和 Docker 镜像由 GitHub Actions 构建。使用自动添加 IPv6 地址功能的 Docker 部署，请按[中文说明](https://github.com/Victor-Tau/Resin/blob/v1.6.3/README.zh-CN.md#一个-ipv4-socks5-端口为不同账号分配固定-ipv6)配置主机网络和 `CAP_NET_ADMIN`。
